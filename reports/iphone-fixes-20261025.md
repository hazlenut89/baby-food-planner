## 구현
- quick-sheet만 native bottom sheet로 표시. 외부 클릭·닫기·키보드 Escape 지원, 입력 선택 후 독립 페이지 사용.
- 입력 페이지 구조 유지. 날짜 이동도 V1/V3 페이지 상태로 처리하며 브라우저 뒤로가기로 닫음.
- 중기/후기 간식 UI 저장·수정·삭제 검증. 초기 단계 비활성 이유를 표시. 간식만 있는 날짜에서 월간 라벨이 생략되던 오류 수정. 실기기에서 보고된 ‘버튼을 눌러도 안 됨’ 자체는 중기 설정의 자동화 환경에서 재현되지 않았으며 실기기 재확인 필요.
- 끼니·간식 추가를 크림색 테두리 버튼으로 표시.
- V1 현재 재고 상세를 active 배치만 조회하도록 수정. 제조일별 과거 기록 조회는 보존. V3 삭제 후 열린 편집기를 닫아 오래된 상태가 남지 않게 처리.
- 날짜 입력의 기본 appearance, box sizing, 최소 너비와 부모 레이아웃 보완. 잘라 가리는 overflow 방식 사용 안 함.
- 제조 이력 버튼·메타데이터 간격, 메뉴 SVG, 홈 화면 안내 상시 메뉴, V3 ‘기존 화면 보기’ 문구 적용.
- 통계 좌측 축의 100%/0% 레이블 제거, 상단 카드 간격 보완. 계산식 변경 없음.
