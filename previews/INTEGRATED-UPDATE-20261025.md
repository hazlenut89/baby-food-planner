## 모바일 편집

PC는 native dialog를 유지한다. V1 기존 큐브/식재료의 문서 페이지 구조는 유지하며 viewport 고정 패치를 제거했다. 브라우저 뒤로가기는 별도 구현하지 않았으며 화면 내 취소/닫기를 사용한다.

모바일 날짜·보관 방식·프로필의 2열 입력은 1열로 변경했다. 이미지 선택기 등 다른 기능의 visualViewport 코드는 이번 편집 페이지 높이 계산에 사용되지 않는다.

## 간식과 식재료
기존 meals 배열에 type:snack, 별도 slot(4 이상)을 추가하는 방식이며 기존 저장 기록을 일괄 마이그레이션하지 않는다. 초기 추가는 코어에서 차단하고 중기/후기에서 선택 가능하다. 일반 식사 3끼 제한과 별개이며 일별 카드 및 월간·이미지 표시에 간식으로 표시한다. 공용 saveMeal의 큐브 원장을 사용한다. V3 통계는 이유식만 집계하고 간식 제외를 명시한다. 간식별 계획·실제 양은 날짜 카드에 별도 표시한다. 실제 양 빈 값=미확인, 0=미섭취, 양수=섭취다.

저장된 식단의 직접 입력 식재료를 맵에 자동 등록한다. 별칭 매칭만 적용하며 기존 ID/이름을 변경하지 않는다. 카테고리는 임의 추정하지 않고 unknown, 선호도/알레르기도 unknown이다. 최초 계획 일수/가능한 날짜를 기록하며 실제 섭취량 양수인 경우에만 최초 섭취를 기록한다. 기존 수동 섭취일·선호도·알레르기·메모는 보존한다. 식단 삭제 시 식재료의 첫 섭취 기록을 삭제하지 않는다. 제품 항목은 자동 식재료 등록에서 제외한다.
